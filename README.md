# 💊 Proyecto Farmacia - Backend

> Sistema de gestión para una farmacia. Clientes, medicamentos y ventas, todo en orden.

[Java](https://img.shields.io/badge/Java-17-orange)
[Spring Boot](https://img.shields.io/badge/Spring_Boot-3.0-green)
[MySQL](https://img.shields.io/badge/MySQL-8.0-blue)

---

## ✨ ¿Qué hace?

| Módulo | Función |
| :--- | :--- |
| 👤 **Clientes** | Registrar, buscar, actualizar y eliminar clientes |
| 💊 **Medicamentos** | Controlar stock, precio y inventario |
| 🧾 **Ventas** | Vender, validar stock y calcular total |

---

## 🛠️ Tecnologías
☕ Java 17 - 🌱 Spring Boot - 🗄️ MySQL - 📦 Maven - 💻 IntelliJ IDEA

---

## 🚀 Cómo correrlo

1. Crear la base de datos `farmacia` en MySQL
2. Configurar usuario y contraseña en `application.properties`
3. Correr `FarmaciaApplication.java` en IntelliJ

Servidor: **http://localhost:8080**

---

## 📁 Estructura
Controller -> Endpoints / Service -> Lógica / Repository -> Base de datos / Entities -> Tablas / DTO -> Datos / Excepciones -> Errores
